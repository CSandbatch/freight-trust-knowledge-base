## Scope boundary

This task authorizes public-source retrieval, local row-level processing, synthetic fixtures,
schemas, deterministic engineering, source-card corrections and aggregate reporting. It does not
authorize model training, benchmark labeling, reviewer recruitment, human-behavior research,
confirmatory holdout access, source-row redistribution, legal-person adjudication, or any fraud,
safety, enforcement or deployment claim.

- Raw and row-level products live only under ignored `data/raw/` and `data/derived/` paths.
- The public vault receives hashes, aggregate counts, source facts, methods and limitations only.
- The RC1 semantic standard remains a human freeze candidate; this task freezes an engineering
  build slice, not the legally controlling identity answer.
